# 🩺 Sehat Saathi

> **Bringing Quality Healthcare Closer to Every Village.**

An AI-powered rural healthcare ecosystem designed to bridge the healthcare gap in underserved communities through intelligent telemedicine, AI-assisted health guidance, and accessible digital healthcare services.

Built for the **Smart India Hackathon (SIH)** under the problem statement:

> **AI-Assisted Rural Healthcare Ecosystem for Telemedicine Access in Nabha**

---

## 🌍 Overview

Sehat Saathi is a modern healthcare platform focused on improving healthcare accessibility in rural India.

The project is built with **Nabha, Punjab** as the pilot region while being designed to scale across rural India.

Our mission is to empower rural communities with AI-assisted healthcare, making quality medical services more accessible, affordable, and user-friendly.

---

## ✨ Key Features

- 🤖 AI-Powered Symptom Checker (Google Gemini)
- 👨‍⚕️ Doctor Discovery & Consultation
- 📅 Appointment Booking
- 💊 Digital Prescription
- 📹 Video Consultation Interface
- 🏥 Nearby Primary Health Centres (PHCs)
- 🚨 Emergency SOS
- 💡 Personalized Health Tips
- 👨‍👩‍👧 Family Health Profiles
- 🌐 Rural-First User Experience

---

## 🎯 Problem Statement

Rural communities often face challenges such as:

- Limited access to qualified doctors
- Long travel distances to hospitals
- Poor healthcare awareness
- Language barriers
- Low digital literacy
- Delayed medical consultation

Sehat Saathi aims to bridge these gaps using AI-powered healthcare assistance and digital telemedicine.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/sehat-saathi.git
```

Navigate to the project:

```bash
cd sehat-saathi
```

Frontend:

```bash
cd client
npm install
npm run dev
```

Backend:

```bash
cd server
npm install
npm run dev
```
